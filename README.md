# Abandoned-and-Forgotten-Things.
東方棄忘録　～ Abandoned and Forgotten Things is a TTRPG based on Touhou Project and Mystical Yokai of Neofantasia (MYON for short)

Project's primary language is Russian. Eng translation is possible in the future. If you want to translate this project in your own language you can fork this repo, just don't forget to tag me as a an original author.

**This project utilizes AI for image generation, some of the descriptions and for note layout. DNI if that's a hard turn-off for you!** If are an author of any non-AI images, contact me if you want them taken down.
